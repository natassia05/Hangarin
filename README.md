# Hangarin — Task & To-Do Manager

Hangarin is a simple **Django-based Task and To-Do Manager** designed to help users organize and manage their daily tasks.

## Features

- Create, update, and delete tasks
- Set task status and deadlines
- Organize tasks by category and priority
- Add notes to tasks
- Create subtasks
- User login and registration
- Django Admin management
- Faker-generated sample data

## Built With

- Python
- Django
- SQLite
- HTML & CSS
- Faker

## Purpose

This project was created as a **Django web development project** to practice database models, forms, views, templates, authentication, Django Admin, and deployment.

## Deployment

The application is deployed using **PythonAnywhere**.
